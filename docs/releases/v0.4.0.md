# Skynet-EDR v0.4.0 — reliable passive AI-agent detection

Skynet-EDR v0.4.0 is an installable **prerelease** for evaluation and lab deployment. It remains passive and read-only: it detects and records but does not block agent actions.

## Highlights

- Added `skynet-edr doctor` for fail-closed package, posture, store, and local-readiness checks.
- Added private, redaction-safe `skynet-edr diagnostics collect` bundles without raw events by default.
- Added deterministic ordered sequence correlation with same-trace/session joins and bounded windows.
- Added eight conservative AI-agent rules: `EDR-MCP-001`, `EDR-CONFIG-001`, `EDR-CRON-001`, `EDR-PI-001`, `EDR-MSG-001`, `EDR-NET-001`, `EDR-SCOPE-001`, and `EDR-PERSIST-001`.
- Connected built-in sequence detections to canonical Hermes/OpenClaw spool ingestion and durable local incidents.
- Added clean-container DEB/tarball install/remove smoke checks plus RPM/Arch content validation.
- Added strict public-download checksum and binary-version verification.
- Hardened CodeQL, Semgrep/Dependabot, secret-scan handling, and release workflow immutability.

## Install quickly

Download the package for your distribution together with `checksums.txt`, then verify it:

```bash
sha256sum -c checksums.txt --ignore-missing
```

Debian/Ubuntu/Mint:

```bash
sudo apt install ./skynet-edr_0.4.0_amd64.deb
skynet-edr --version
skynet-edr-daemon status
skynet-edr doctor
```

RHEL/Fedora-compatible:

```bash
sudo dnf install ./skynet-edr-0.4.0-1.x86_64.rpm
```

Arch:

```bash
sudo pacman -U ./skynet-edr-0.4.0-1-x86_64.pkg.tar.zst
```

Tarball:

```bash
tar -xzf skynet-edr-0.4.0-x86_64-unknown-linux-gnu.tar.gz
cd skynet-edr-0.4.0-x86_64-unknown-linux-gnu
sha256sum -c SHA256SUMS
sudo ./install.sh
```

## Important limitations

- No inline blocking or guard/enforcement mode.
- No privileged kernel/eBPF sensor coverage.
- No signed packages, SBOM/provenance attestation, or distribution repositories yet.
- Some rules depend on telemetry fields that not every adapter emits; missing indicators mean missing coverage, not proof of safety.
- Sequence evaluation currently scans the local canonical event store and is intended for low-volume single-host evaluation.
